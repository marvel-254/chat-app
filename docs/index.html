Features

Built for how you actually message

Every detail considered — from the way bubbles group together to the subtle glow when a message is read.

End-to-End Encrypted

Your messages stay between you and the recipient. No servers, no third parties, no exceptions.

Real-Time Sync

Messages appear instantly across all your devices. No refresh needed, no delay.

Dark Mode Native

Not an afterthought — designed from the ground up for OLED screens with true blacks and indigo accents.

Smart Message Grouping

Consecutive messages merge seamlessly. Clean, readable conversations without visual clutter.

Read Receipts

Know when your message is delivered and read. Subtle checkmarks that don't demand attention.

Typing Indicators

See when someone's composing a reply. Real-time presence that keeps conversations flowing.

Fluid Conversations

Messages from the same sender merge into continuous bubbles with adaptive rounded corners. No awkward gaps, no visual noise.

Per-Message Timestamps

Every message shows its exact time in a clean 12-hour format. Date separators appear automatically — Today, Yesterday, or the date.

Read Receipts

Double checkmarks turn green when read. Gray when delivered. Instant feedback without the anxiety.

Adaptive Composer

Expands up to 5 lines as you type. Mic icon morphs into send button. Enter to send, Shift+Enter for new line.

True Dark Theme

Pure black backgrounds for OLED. Indigo primary with cyan accent. Every surface, border, and shadow tuned for low light.

Typing Awareness

Subtle "Pulse is typing…" indicator appears while the other person composes. Fades smoothly when they stop.
