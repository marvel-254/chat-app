5. Accessibility & Implementation Guidelines

WCAG 2.2 Level AA Requirements

  • Contrast Ratios: Normal text must meet at least 4.5:1 against surfaces; large text (18px+ or 14px bold) must meet 3:1. Our primary text (#F2F1F8) on #08090D achieves a contrast ratio greater than 16:1.
  • Keyboard Navigation: Every interactive element (buttons, links, form inputs) must have a visible :focus-visible ring with high-contrast outline offset.
  • Reduced Motion: All CSS keyframes, transitions, and hover transforms must gracefully disable when prefers-reduced-motion: reduce is signaled by the operating system.
  • Semantic HTML: Use native <button>, <a>, <nav>, and heading tags (<h1>–<h3>) rather than generic divs.

Adding New Variants

  • Always define new colors in css/tokens.css under the appropriate semantic category (--nyx-color-*).
  • Consume tokens in css/components.css using BEM class conventions (.nyx-block__element--modifier).
  • Never hardcode hex values directly into component declarations.
